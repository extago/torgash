# What's new

The reference module keeps a changelog so that yours can copy its shape: a
`CHANGELOG.md` in the module's root is shown on the modules screen — the version
badge opens it, and it is the last tab of the module's documentation. A
translation sits beside it as `CHANGELOG.<locale>.md`.

## 1.0.0

- Routes, a hook, a setting, a migration, a theme override and documentation —
  everything a module usually needs, in one place to copy from.
