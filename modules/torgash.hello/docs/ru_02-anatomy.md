# Устройство модуля

```
modules/torgash.hello/
├── manifest.json     id, provider, autoload, requires, settings, permissions, admin_menu
├── src/              PSR-4, один ServiceProvider
├── views/            <module.id>::name — тема может их переопределить
├── lang/             en.json, ru.json — строки интерфейса
├── migrations/       таблицы m_<name>_*; установка их применяет, удаление откатывает
└── docs/             эта папка
```

## Правила, которые не гнутся

1. Модуль никогда не патчит ядро или другой модуль. Расширяется через хуки
   (`hook_listen` / `hook_filter` / `hook_action`) и переопределение представлений.
2. Установка и удаление не оставляют следов: таблицы модуля с префиксом
   `m_<name>_`, а имя файла миграции уникально среди *всех* модулей (Laravel
   различает их только по имени файла).
3. Настройки объявляются в манифесте и читаются `setting('module.id', 'key')` —
   значения по умолчанию из манифеста, актуальные из базы.
