# Обзор

`torgash.hello` — эталонный модуль: самое маленькое, что всё ещё является
настоящим модулем. Копируйте его форму, когда начинаете новый.

Показывает по одному файлу на каждую вещь:

- **маршрут** (`routes.php`) и **представление** (`views/hello.blade.php`)
- **миграцию** с таблицей `m_hello_*`, которую установка создаёт, а удаление сносит
- слушатель **хука**, **настройку** из манифеста и **переопределение темы**
- и теперь **папку `docs/`** — страницы, которые вы читаете.

## Документация едет вместе с кодом

У любого модуля с папкой `docs/` на экране «Модули» появляется иконка книги.
Флага в манифесте нет: сама папка и есть признак — так же, как `settings` в
манифесте включает шестерёнку.

Страница — это Markdown-файл:

| Файл | Что это |
|---|---|
| `overview.md` | страница на базовом языке |
| `ru_overview.md` | её перевод на русский |
| `01-overview.md` | `01-` задаёт порядок вкладок; слаг всё равно `overview` |

Сырой HTML в Markdown вырезается — документацию модуля пишет его вендор, третья
сторона, — но картинки работают: положите их рядом с `.md` и сошлитесь
относительным путём.
