# Импорт

Обмен данных → Импорт принимает файл CSV, XML или YML — вашу же выгрузку,
прайс поставщика, каталог из другого движка — и записывает его строки в
магазин: товары, категории, характеристики и остальное из списка.

## Изменить много товаров сразу

Названия, адреса, описания, категории, цены, остатки, характеристики: сотню
товаров быстрее поправить одним файлом, чем сотней форм.

1. Выгрузите товары с колонками, которые будете менять (профиль экспорта в
   CSV), или напишите файл сами: колонка `sku` и колонки, которые меняются.
2. Поправьте ячейки в таблице и сохраните её как CSV.
3. Импортируйте. Строка находит свой товар по **внешнему ID**, затем по
   **артикулу**. Записываются только колонки, которые есть в файле; всё
   остальное остаётся как было.

Изменённый адрес оставляет старый переадресацией, как и форма товара. Строка,
артикул которой не совпал ни с одним товаром, создаёт новый — если не снято
**«Создавать то, что не найдено»**; тогда она пропускается. Новому товару
нужно название: строка без него пропускается и названа в итогах, а остальной
файл импортируется.

## Колонки

Каждая колонка файла идёт в одно из полей магазина или пропускается. Экран
угадывает сам: по собственному имени поля — ключу (`sku`, `name_ru`,
`price_units`) или заголовку, который пишет экспорт («Название (RU)»), — по
тому, как поле называют другие системы («Product code», «Артикул», «VAR
Feature 2 [Цвет]»), характеристику — по её названию. Текст идёт в один язык
или сразу во все («Все языки»).

У колонки может быть **формула**, которая меняет значение при импорте:
`ending($value * 1.2, 90)` делает из закупочной цены цену, оканчивающуюся на
90, `col("Закупка")` читает другую колонку. Если формулу для строки посчитать
не удалось, это поле строки остаётся как было, а в итогах сказано, в каких
строках.

## Пресеты

Как был прочитан файл — куда идут колонки, их формулы, разделитель и
настройки ниже — сохраняется **пресетом** под именем, которое вы дадите.
Следующий файл с теми же колонками (достаточно четырёх из пяти) читается так
же, без настройки.

## Проверка, потом импорт

**«Проверить перед импортом»** показывает, что сделает импорт: сколько строк
создадут, обновят или пропустят запись, первые сто из них и строки, на
которых остановится формула или не хватит названия. Пока ничего не изменилось.
**«Импорт»** затем идёт в фоне: его видно в «Фоновых задачах», с итогами и
заметками («строка 12: создана категория»). Фото, заданные ссылками,
скачиваются после этого отдельной задачей.

Загруженный файл ждёт в **«Незавершённых импортах»**, пока его не
импортируют или не удалят; нетронутый неделю удаляется вместе с файлом.

## Из консоли

Тот же импорт без экрана — для скрипта или для файла, который приходит
каждый день:

    php artisan exim:import prices.csv --dry-run
    php artisan exim:import prices.csv

Колонки сопоставляются так же, как на экране: по их именам или по пресету,
сохранённому для них, — а строки записывает та же фоновая задача, её видно в
«Фоновых задачах». Колонка, которая не идёт ни в одно поле, останавливает
импорт: переименуйте её, сохраните для файла пресет на экране или добавьте
`--skip-unknown`. Формула, которую не прочитать, тоже останавливает.

| Ключ | |
|---|---|
| `--dry-run` | То, что сказала бы **«Проверить перед импортом»**; ничего не меняется |
| `--preset="Поставщик"` | Читать файл по этому пресету (имя или номер) |
| `--no-preset` | Сопоставлять колонки только по их именам |
| `--skip-new` / `--create-new` | Строки, которые ни с чем не совпали: пропускать (прайс) / создавать |
| `--images=missing` | Ссылки на фото: `empty` (только товарам без фото), `missing`, `replace` |
| `--entity=category` | Не товары; `--fields` рядом покажет, что принимается |
| `--fields` | Все поля и имена колонок, из которых они читаются |
| `--user=you@example.com` | Импорт — этого сотрудника: в «Фоновых задачах» и журнале аудита |
| `--queue` | Отдать воркеру очереди, а не выполнять в консоли |

Без `--user` импорт ничей и не оставляет записей в журнале аудита — как и
всё, что делается из консоли. Как читается файл (разделитель, кодировка,
запись XML) и его формулы берутся из пресета: настройте один раз на экране,
потом запускайте файл из консоли.
