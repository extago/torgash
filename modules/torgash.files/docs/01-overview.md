# File manager

A folder of the shop's own pictures and files, each with a **permanent public
link**: icons and pictures for blocks, photos for a marketplace feed, a price
list to hand out. Admin → Content → **File manager**.

## Uploading

Press **Upload files** or drop files anywhere on the list — as many as you
like. They go up a few at a time, each with its own progress bar; a file the
shop does not take is named with the reason and the rest carry on.

What is taken is the module's settings: the types (read from the file
itself, not from its name), the largest size and, if wanted, shrinking big
photos on the way in. An SVG is rebuilt from what draws and nothing else, so
a script hidden inside one never reaches the shop's pages.

## The link never changes

The link of a file is made when it is uploaded and stays the same for good:
renaming a file only changes the name shown here, and folders exist only to
find files here — moving a file to another folder leaves its link alone.
That is what makes it safe to paste a link into a block, a product field or
a feed and tidy the folders later.

What the link ends in is a setting: the uploaded name transliterated
(`red-boot.jpg`, `red-boot-2.jpg` for the next one of that name) or a short
random code (`k3f9x2qa7m1b.jpg`). It applies to new uploads.

Deleting a file — or a folder with everything in it — breaks its link; the
screen asks first.

## Photos for a marketplace

Tick the photos of a product and press **Copy links**: the links are copied
separated by commas, ready to paste into a text field such as "Photos for
Avito" and go out with the feed.
