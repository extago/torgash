# Файловый менеджер

Папка с картинками и файлами магазина, у каждого — **постоянная публичная
ссылка**: иконки и картинки для блоков, фото для фида маркетплейса, прайс-лист
для покупателей. Админка → Контент → **Файловый менеджер**.

## Загрузка

Нажмите **Загрузить файлы** или перетащите файлы в любое место списка —
сколько угодно. Они уходят по несколько сразу, у каждого своя полоса
прогресса; файл, который магазин не принимает, назван с причиной, остальные
загружаются дальше.

Что принимается — настройки модуля: типы (определяются по содержимому файла,
а не по имени), самый большой размер и, если нужно, уменьшение больших фото
при загрузке. SVG пересобирается только из того, что рисует, поэтому
спрятанный в нём скрипт до страниц магазина не доходит.

## Ссылка не меняется

Ссылка на файл появляется при загрузке и остаётся навсегда: переименование
меняет только название здесь, а папки нужны лишь для порядка в менеджере —
перенос файла в другую папку ссылку не трогает. Поэтому ссылку можно
спокойно вставить в блок, поле товара или фид, а папки разобрать потом.

Чем заканчивается ссылка — настройка: исходное имя транслитом
(`red-boot.jpg`, для следующего с тем же именем — `red-boot-2.jpg`) или
короткий случайный код (`k3f9x2qa7m1b.jpg`). Действует на новые загрузки.

Удаление файла — или папки со всем содержимым — ломает его ссылку; экран
переспрашивает.

## Фото для маркетплейса

Отметьте фото товара и нажмите **Скопировать ссылки**: ссылки копируются
через запятую — готово для текстового поля вроде «Фото для Авито», которое
уходит в фид.
