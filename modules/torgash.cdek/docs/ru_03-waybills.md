# Накладные

У заказа, отправляемого СДЭК, на экране заказа (правая колонка) есть карточка
**Накладная СДЭК**. Сотруднику нужно право **Создание и печать накладных
СДЭК** — оно отдельно от права настраивать интеграцию.

## Перед первой накладной

В настройках модуля, группа **Накладные**:

- **Офис СДЭК, где вы сдаёте посылки** — его код (MSK2 …). Нужен для
  способов, где *вы сдаёте посылки в офис*.
- **Отправитель: компания / контактное лицо / телефон** — печатаются в
  накладной.
- **Адрес забора** — нужен для способов, где *посылки забирает курьер СДЭК*;
  город — город отправителя.

## Создание

Карточка начинается с посылки: вес — из веса товаров, габариты — из их
размеров (или посылки по умолчанию), всё можно поправить. **Взять оплату при
получении** отмечено, если по заказу остался долг и заказ не ждёт онлайн-оплаты;
берётся ровно оставшаяся сумма — скидка, подарочный сертификат или уже
внесённая часть повторно не взимаются. Объявленная стоимость товаров — полная
в любом случае (СДЭК их страхует).

Остальное берётся из заказа, каким он был оформлен: тариф выбранного
покупателем пункта (постамат отправляется другим кодом, чем ПВЗ), код пункта
или адрес для курьера, имя и телефон получателя.

## Дальше

СДЭК регистрирует заказ не сразу после приёма: пока не пришёл номер, в карточке
написано **регистрируется…**. Затем:

- **Печать накладной** — квитанция, два экземпляра (один остаётся у вас);
- **Печать этикетки** — наклейка со штрихкодом A6 на коробку;
- **Обновить** — спросить статус у СДЭК сейчас; планировщик и так спрашивает
  каждые полчаса, пока посылка не вручена или не вернулась;
- **Отменить накладную** — только пока посылки у СДЭК ещё нет. После этого можно
  сделать новую; её номер — номер заказа с `-2`, потому что один номер СДЭК
  дважды не принимает.

Если СДЭК принял накладную, а потом отклонил, карточка покажет причину и снова
форму для следующей попытки.

Покупатель видит номер СДЭК со ссылкой на отслеживание на странице своего
заказа.

## Тестовая среда

Публичный тестовый аккаунт СДЭК **не умеет наложенный платёж**: такая
накладная принимается, но номер не получает и не печатается. Снимите галку,
чтобы пройти весь путь. Город тестового аккаунта — Новосибирск.

Другой модуль может реагировать на смену статуса через хук
`cdek.waybill.status_changed` (`['waybill' => …, 'from' => прежний код]`).
