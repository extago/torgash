# Скорость: куда уходит время

Экран «Скорость» (Система → Скорость) отвечает на один вопрос: **на что эта
страница тратит время?** Не «магазин тормозит», а «страница товара тратит
100 мс на запуск движка, 100 мс в базе, 35 мс в хуках модулей — и 30 из них
съедают отзывы».

## Что меряется

Доля настоящих запросов (`Доля измеряемых запросов`, по умолчанию 20%). Для
каждого:

* **Запуск движка** — от старта PHP до готовности движка. Одинаков на всех
  страницах; большой, когда выключены кэши или диск медленный.
* **База данных** — каждый запрос, его время и его вид.
* **Внешние вызовы** — обращения к другим сервисам (платёжный шлюз, API
  перевозчика) с адресом хоста.
* **Хуки модулей** — слушатели хуков каждого модуля, их СОБСТВЕННОЕ время (хук,
  который модуль вызвал, а ответил другой модуль, засчитывается ответившему).
* **Код и шаблоны** — всё, что никто выше не присвоил: контроллер страницы, её
  шаблоны, сам PHP.

Пять частей в сумме дают время страницы. Всё пишется уже после того, как
страница отправлена, — почасовыми итогами по страницам, а не строкой на визит.

## Как читать экран

**Куда уходит время** — страницы по времени, которое они стоят магазину В СУММЕ.
Страница товара, открытая десять тысяч раз по 250 мс, обходится дороже отчёта на
три секунды, открытого дважды, — поэтому она наверху. «Обычно» — медиана, «1 из
20» — 95-й перцентиль: страница, которая обычно быстрая, но иногда грузится две
секунды, видна по маленькому «обычно» и большому «1 из 20». Полоса — один
обычный визит, разложенный на пять частей; наведите на неё, чтобы увидеть цифры.

**Модули** — сколько хуки каждого модуля добавляют к странице, на которой
срабатывают, и сколько из этого — база. Модуль наверху списка, у которого почти
всё время — база, спрашивает данные, которые мог бы спросить один раз на
страницу.

**Спрашивается снова и снова (N+1)** — один и тот же запрос, повторённый при
сборке ОДНОЙ страницы, вместе со строкой кода, которая спросила. Это почти всегда
цикл, достающий по одной строке. Если «откуда спрошено» — шаблон
(`view: …blade.php`), что-то на странице само подгружает свои данные для каждого
элемента; лечится загрузкой для всего списка до цикла.

**Самые дорогие запросы** — виды запросов по суммарному времени в базе. Один
медленный запрос виден по большому «самый медленный»; дешёвый, но спрашиваемый
везде, — по числу запусков.

**Шкалы** — страницы медленнее порога сохраняют полную шкалу: каждый запрос,
внешний вызов и хук по порядку, на одной оси времени.

## Трассировать мои страницы

Кнопка наверху десять минут меряет каждую страницу, которую открываете ВЫ, что
бы ни говорила выборка, и сохраняет шкалу каждой. Нажмите, откройте в соседней
вкладке страницу, которая кажется медленной, вернитесь — её шкала будет первой в
списке.

Привязка — к вашему адресу (решать надо ещё до того, как появится сессия),
поэтому те, кто сидит за тем же адресом, эти минуты тоже трассируются. Им это
ничего не стоит.

## Сколько это стоит

Неизмеряемый запрос — одно чтение настройки и одна проверка на запрос к базе и на
хук. Измеряемый — несколько миллисекунд учёта и четыре записи уже после отправки
ответа. Выключите замер в настройках модуля — прекратится и учёт. Часы старше
`keep_days` (по умолчанию 30) удаляются каждую ночь.

## Чего он не меряет

Того, что происходит в БРАУЗЕРЕ, — картинки, скрипты, прыжки вёрстки (Core Web
Vitals). Эти данные приходят из браузеров посетителей, то есть нужен публичный
адрес, принимающий данные, и это отдельная работа с защитой.
