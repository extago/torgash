# Свои поля оформления

Оформление заказа спрашивает обычное: для кого заказ, как связаться, куда
доставить, как оплатить. Всё остальное, что нужно знать вашему магазину, —
это ваши поля: **Продажи → Поля оформления**.

## Каким бывает поле

| Тип | Как выглядит |
|---|---|
| Строка текста | одна строка |
| Несколько строк | поле на несколько строк |
| Выпадающий список | список на выбор |
| Один из нескольких | ответы кнопками в ряд, одно нажатие |
| Галочка | флажок с вашим текстом рядом |
| Дата | календарь |

У поля есть название, описание под ним, подсказка внутри и отметка
**обязательное**.

## Где и кого спрашивать

- **Место на странице** — под получателем, под доставкой или над
  комментарием к заказу.
- **Кого спрашиваем** — всех, только частных лиц или только компании (если
  магазин принимает заказы от компаний — настройки оформления).
- **Только для этих способов доставки** — отметьте способы, к которым
  относится поле; ничего не отмечено — при любой доставке.

Поле показывается только там, где оно нужно, и **обязательно только там**:
вопрос для курьера с отметкой «обязательное» не мешает заказу с самовывозом.
Покупатель меняет доставку — поле появляется или исчезает.

## Куда попадают ответы

В заказ, строками «Название: ответ» — и никогда не в комментарий
покупателя, он остаётся его словами:

- карточка заказа в админке;
- страница заказа у покупателя;
- письма — `{order_details}` выводит их вместе со всем заказом,
  `{order_fields}` — только их;
- автоматизации — `{{ order.fields.КОД }}` для одного ответа,
  `{{ order.fields_text }}` для всех;
- экспорт заказов (колонка «Поля оформления») и API (`fields`).

**Код** — это имя, по которому автоматизация обращается к ответу. Если
оставить его пустым, он получится из названия.

Выбранный вариант записывается на основном языке магазина, на каком бы языке
ни покупали, поэтому ответы на «Как вы нас нашли» можно посчитать: пишите
варианты на всех языках в одном порядке — они сопоставляются по номеру
строки.

Удаление поля не трогает заказы: каждый хранит ответы, которые получил.

## Примеры

**Цветочный магазин — «Кому передать букет».** Строка текста, под доставкой,
только для курьера, обязательное. Описание: «Имя и телефон человека, которому
передаём букет». При самовывозе не спрашивается.

**«Как вы нас нашли».** Один из нескольких, над комментарием, необязательное.
Варианты: Google, Instagram, TikTok, Посоветовали знакомые. Описание: «Один
вопрос — спасибо, если ответите».

**Реквизиты компании.** Строки текста только для компаний:

- Россия: КПП, ОГРН, юридический адрес, банк, БИК, расчётный счёт;
- Украина: плательщик НДС (галочка), IBAN, юридический адрес.

Название компании и налоговый код (ИНН / ЕДРПОУ) оформление уже спрашивает
само.

**Открытка к подарку.** Несколько строк, над комментарием: «Текст открытки —
напишем от руки».

**Дата доставки.** Дата, под доставкой, только для курьера.
