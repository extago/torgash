# Настройка Stripe

1. **Секретный ключ.** dashboard.stripe.com → Developers → **API keys**.
   Пользуйтесь `sk_test_…`, пока не увидите первый прошедший платёж.
2. **Вебхук.** Workbench → **Webhooks** → *Create an event destination* → ваш
   аккаунт, **версия API `2024-06-20`**, и такие события:

   * `checkout.session.completed`
   * `checkout.session.async_payment_succeeded`
   * `checkout.session.async_payment_failed`
   * `checkout.session.expired`
   * `payment_intent.succeeded`
   * `payment_intent.amount_capturable_updated`
   * `payment_intent.payment_failed`
   * `payment_intent.canceled`
   * `charge.refunded`

   Адрес: `https://<ваш магазин>/payment/stripe/callback`. После этого Stripe
   покажет **секрет подписи** (`whsec_…`).
3. Админка → **Оплата** → откройте способ оплаты, который видит покупатель → в
   блоке **«Приём денег»** выберите **Stripe**, вставьте оба секрета и, пока
   ключ `sk_test_`, включите **тестовый режим**. Сохраните.

Версия API важна: движок фиксирует свои запросы на `2024-06-20`, а форма событий
вебхука определяется версией, выбранной для АДРЕСА. Одна версия с обеих сторон —
значит, обе стороны описывают одни и те же объекты.

## Как это работает

Покупатель уходит на страницу **Checkout**, размещённую у Stripe. Оплаченным
заказ делает только вебхук — он проверяется секретом подписи (HMAC-SHA256 над
временем и сырым телом) и отклоняется, если ему больше пяти минут, так что
перехваченное сообщение нельзя проиграть позже. Заказ назван внутри подписанного
события, а не в адресе.

На машине разработчика пользуйтесь Stripe CLI (`stripe listen --forward-to
https://torgash.local/payment/stripe/callback`); на время проверки в форму
вставляется его `whsec_`.

## Что умеют кнопки на заказе

* **Обновить** — спросить Stripe, что он думает сейчас.
* **Списать холд** — забрать замороженное (при «Сначала холд»), целиком или меньше.
* **Вернуть** — вернуть деньги целиком или частично. Двойной клик — один возврат:
  у каждого возврата есть ключ идемпотентности.
* **Отпустить холд** — отпустить замороженные деньги, не списывая их. У Stripe это
  другой вызов, чем возврат, и разница важна: возврат денег, которые не уходили с
  карты, стоит магазину комиссий дважды.
* **Отменить** — закрыть неоплаченную страницу оплаты.

## Что стоит знать

* **Отклонённая карта не проваливает заказ.** Покупатель ещё на странице Stripe и
  может попробовать другую карту; отказ записан в журнал.
* **Валюты**: любые, которые принимает Stripe, кроме тех, что он считает не в
  сотых (иена, вона, динары…). Такие отклоняются с объяснением ещё до того, как
  покупатель уйдёт с сайта: сотые магазина, отправленные как иены, — списание в
  сто раз больше.
* **На странице одна строка — сам заказ.** Строки заказа — в книгах магазина, а
  списание может быть в другой валюте.
