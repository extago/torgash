# Настройка Новой Почты

## 1. Ключ API

Вставьте ключ API Новой Почты в настройки модуля
(**Модули → Новая Почта → шестерёнка**). На экране данных есть кнопка
**Проверить** — она делает один живой запрос, так что вы сразу узнаёте, рабочий
ли ключ, а не из упавшей через десять минут фоновой задачи.

Всё, что ниже, требует ключа.

## 2. Синхронизация справочника пунктов

**Модули → Новая Почта → ссылка на документацию открывает экран данных** →
**Синхронизировать справочник**. Тянет ~27 000 населённых пунктов перевозчика и
~11 000 «городов» в `m_np_settlements` (около 17 секунд). Идёт фоновой задачей —
следите в разделе **Система → Фоновые задачи**.

Когда в проекте заработает планировщик, справочник обновляется сам раз в неделю;
до тех пор нажимайте кнопку, когда список перевозчика сдвинулся.

## 3. Сопоставление пунктов с реестром

**Сопоставить с реестром** связывает каждый пункт Новой Почты с местом из
`torgash.locations`. На живых украинских данных автоматически сходится около
90%; остальное не имеет пары на стороне перевозчика (Крым, оккупированные
территории, сёла, которых у перевозчика нет) и просто не предлагает Новую
Почту. См. [Сопоставление пунктов](?doc=place-matching).

Несопоставленный пункт виден в отдельном списке, где его можно привязать
вручную — ручная привязка переживает любой следующий автопрогон.

## 4. Отделения

Отделения тянутся **лениво, по городу**: первое оформление заказа, назвавшее город,
платит один запрос, все следующие читают кэш (по умолчанию сутки). Магазину,
которому удобнее держать всю страну в базе заранее, кнопка **Загрузить все
отделения** обходит все сопоставленные города, крупные вперёд, в рамках бюджета
времени — запустите ещё раз, и прогон продолжится с места остановки.

## 5. Способ доставки

Добавьте способ доставки (**Доставка → Способы**), на вкладке «Перевозчик»
выберите **Считает → Новая Почта** и вариант: **до отделения** или **курьером**.
Для живого расчёта задайте ещё **город отправителя** на экране данных — без него
способ считается по вашей тарифной таблице, и это рабочий режим.
