## What's new

**In short:** enquiries now remember where they were sent from, the way orders do; a backup check that the server does not allow no longer reports a failed backup; and security updates of the components the engine is built on.

### Enquiries
- **An enquiry records the IP address, the browser and its languages** when it is sent. All of it is on the enquiry's card, beside a count of other enquiries from that address and a link to block it. The list can be searched by address.
- **The module's settings choose what is recorded**, separately from orders; all three are on by default. Enquiries sent before this update have none of it.
- **The address and browser are personal data and are treated as such:** they are removed after the retention you set (180 days by default) and when a person's data is erased, and they are included when a person downloads their data.

### Backups
- **A backup check needs the database user to be allowed to create databases.** Without that right the check no longer starts and the run says "blocked", not "failed": nothing is known about the backup itself. The backup plan's form warns about it in advance, and the notification clears as soon as the right is given.

### Delivery
- **A shop serving several countries now starts the country box on its own country**, in the checkout and the cart, instead of "Select a country". If a town is already known, the box is left as it was: the town may be in another country.

### Personal data
- A person's data download now includes the IP address and browser of their orders.

### Security
- Symfony and Laravel components updated. The update closes 11 published vulnerabilities, among them the cleaning of HTML written by staff, email headers and links built from a request's address.

## Что нового

**Главное:** обращения теперь запоминают, откуда их отправили, как и заказы; проверка бэкапа, которую не разрешает сервер, больше не сообщает о провале; обновлены компоненты, на которых построен движок, — это обновление безопасности.

### Обращения
- **Обращение записывает IP-адрес, браузер и его языки** при отправке. Всё это видно в карточке обращения, там же счётчик других обращений с этого адреса и ссылка на блокировку. По адресу можно искать в списке.
- **Что записывать, выбирается в настройках модуля**, отдельно от заказов; по умолчанию включено всё. У обращений, отправленных до этого обновления, этих данных нет.
- **Адрес и браузер — персональные данные, и обращаются с ними соответственно:** они стираются по сроку хранения, который вы задали (по умолчанию 180 дней), и при удалении данных человека, а при выгрузке его данных попадают в файл.

### Бэкапы
- **Для проверки бэкапа пользователю базы нужно право создавать базы.** Без него проверка больше не начинается, и запуск помечается «заблокирован», а не «провален»: о самом бэкапе ничего не известно. Форма плана предупреждает об этом заранее, а уведомление исчезает, как только право выдано.

### Доставка
- **Магазин с несколькими странами теперь сразу показывает свою страну** в оформлении заказа и в корзине, а не «Выберите страну». Если город уже известен, поле остаётся как было: город может быть в другой стране.

### Персональные данные
- В выгрузку данных человека теперь входят IP-адрес и браузер его заказов.

### Безопасность
- Обновлены компоненты Symfony и Laravel. Закрыто 11 опубликованных уязвимостей, среди них — очистка HTML, написанного сотрудниками, заголовки писем и ссылки, построенные по адресу запроса.
