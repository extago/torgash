## What's new

**In short:** pages that have to be built are ready sooner, product pages most of all, and counting a view no longer keeps the visitor waiting.

### Speed
- **Pages with many pictures make far fewer requests to the database.** The parent categories behind a picture's description were looked up one at a time, up to 50 requests on a product page. Now it is one.
- **Products with variations are grouped into cards about twice as fast** in blocks and lists that go through the whole catalogue. Measured on a catalogue of 800 products.
- **Counting a view no longer keeps the visitor waiting.** The view and the popularity points are now recorded after the page has been sent, on pages kept ready as well.
- **A product page reads only the landing it shows,** not the HTML and styles of all of them.

### Speed report
- **Work done after a page has been sent no longer counts towards that page.**

### Fixes
- **A broken category tree could hang a page.** If a category ended up among its own parents, the page never finished. It now opens.

## Что нового

**Главное:** страницы, которые приходится собирать заново, готовы быстрее, особенно страницы товаров, а подсчёт просмотра больше не заставляет посетителя ждать.

### Скорость
- **Страницы с большим числом картинок делают намного меньше запросов к базе.** Родительские категории для описания картинки искались по одной, на странице товара до 50 запросов. Теперь один.
- **Товары с вариациями группируются в карточки примерно вдвое быстрее** в блоках и списках, которые просматривают весь каталог. Замерено на каталоге из 800 товаров.
- **Подсчёт просмотра больше не заставляет посетителя ждать.** Просмотр и баллы популярности записываются уже после отправки страницы, и на готовых страницах тоже.
- **Страница товара читает только ту посадочную, которую показывает,** а не HTML и стили всех сразу.

### Отчёт о скорости
- **Работа, сделанная после отправки страницы, больше не засчитывается в её время.**

### Исправления
- **Ошибка в дереве категорий могла повесить страницу.** Если категория оказывалась среди собственных родителей, страница не открывалась. Теперь открывается.
