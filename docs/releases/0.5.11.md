## What's new

**In short:** the shop's rule for an order's contact now applies to signed-in customers too, and a customer's phone is remembered, so they do not type it again.

### Orders and customers
- **"An order must have" applies to everyone who orders on the storefront** (Settings → Checkout). Before, a signed-in customer could order with any one contact, even where the shop asked for a phone. A customer whose account has no email is still not asked for one. An order a manager creates in the admin is not bound by it, as before.
- **"Phone for calls" in the customer's profile.** A customer types the number the shop should ring, with no code. When the account has no number yet, the customer's first order fills it in. Later orders do not change it: a parcel may be for somebody else. Nobody can sign in with this number.
- **The customer's phone is filled in for them** at checkout, in "Buy in one click" and in a callback request. They only press the button.
- **The manager sees this number on the customer's card,** "Call" dials it, and the customer search finds it, also when picking the customer for a new order.

### Fixed
- **The phone an account confirmed by a code is filled in at checkout.** Only the phone of a saved address was.
- **A one-click request without a name no longer ends in an error.**

### Good to know
- If "An order must have" asks for a phone, registered customers are now asked for it too.
- Numbers from past orders are not copied into accounts: each customer's number appears with their next order.

## Что нового

**Главное:** «Обязательный контакт в заказе» теперь действует и на вошедших покупателей, а телефон покупателя запоминается, чтобы не вводить его снова.

### Заказы и покупатели
- **«Обязательный контакт в заказе» действует на всех, кто оформляет заказ на витрине** (Настройки → Оформление заказа). Раньше вошедший покупатель мог заказать с любым одним контактом, даже если магазин требовал телефон. Покупателя, у которого в аккаунте нет почты, о почте по-прежнему не спрашивают. Заказ, который менеджер создаёт в админке, этому правилу не подчиняется, как и раньше.
- **«Телефон для звонков» в профиле покупателя.** Покупатель указывает номер, по которому ему звонить, без кода. Если номера в аккаунте ещё нет, его сохранит первый заказ покупателя. Следующие заказы номер не меняют: посылка может быть для другого человека. Войти по этому номеру нельзя.
- **Телефон покупателя подставляется сам** в оформление заказа, в «Купить в один клик» и в заявку на звонок. Покупателю остаётся нажать кнопку.
- **Менеджер видит этот номер в карточке покупателя,** «Позвонить» набирает его, а поиск покупателей находит по нему, в том числе при выборе покупателя для нового заказа.

### Исправлено
- **Телефон, подтверждённый кодом, подставляется в оформление заказа.** Раньше подставлялся только телефон из сохранённого адреса.
- **Запрос «в один клик» без имени больше не заканчивается ошибкой.**

### Полезно знать
- Если в «Обязательном контакте в заказе» выбран телефон, его теперь спросят и у зарегистрированных покупателей.
- Номера из прошлых заказов в аккаунты не переносятся: у каждого покупателя номер появится со следующим заказом.
