## What's new

**In short:** a new module, File manager — the shop's own pictures and files in folders, each with a link that never changes: for pictures in blocks and for photos whose links go into a product field and a marketplace feed. The comparison table gets arrows to turn its columns on a computer, and uploaded pictures can be named by a short code instead of their original name.

### File manager (new module)
- **Admin → Content → File manager.** Folders and subfolders, files as tiles with previews or as a list; the choice is remembered.
- **Upload many at once** — press "Upload files" or drop them on the list. Thousands go up a few at a time under one progress bar; a file the shop does not take is named with the reason and the rest carry on.
- **The link never changes.** Renaming a file changes only the name shown in the manager; moving it to another folder leaves its link alone. So a link can be pasted into a block, a product field or a feed, and the folders tidied later.
- **Copy links.** Tick several files and copy their links in one go, separated by commas — ready for a text field such as "Photos for Avito" that goes out with a feed. Ticked files can also be moved or deleted.
- **Safe on a public disk.** The type is read from the file itself, programs and web pages are never accepted, an SVG is rebuilt from what draws. Settings: the types accepted, the largest file, shrinking big photos on upload, and how stored files are named.

### Names of stored files
- A new setting of the Media module, **"Names of stored files"**: as uploaded, transliterated (as before), or a short random code such as `k3f9x2qa7m1b.jpg`. New uploads only — pictures already stored keep their addresses. The File manager has the same setting of its own.

### Comparison
- **Arrows on a computer.** With many characteristics the table's scrollbar was far below; now two arrows stay half-way down the window while the table is on screen and turn it one product column per press. They hide at the ends and when everything fits.

### Fixes
- Variations tab: a disabled variation's row made the status menu opening from it see-through, and the "this product" badge moved out of line when it wrapped under the name.

## Что нового

**Главное:** новый модуль «Файловый менеджер» — картинки и файлы магазина в папках, у каждого ссылка, которая не меняется: для картинок в блоках и для фото, ссылки на которые вписываются в поле товара и уходят в фид маркетплейса. В таблице сравнения на компьютере появились стрелки для листания столбцов, а загруженные картинки можно называть коротким кодом вместо исходного имени.

### Файловый менеджер (новый модуль)
- **Админка → Контент → Файловый менеджер.** Папки и подпапки, файлы плиткой с превью или списком; выбор запоминается.
- **Загрузка пачкой** — кнопка «Загрузить файлы» или перетаскивание на список. Тысячи файлов уходят по несколько сразу под одной полосой прогресса; файл, который магазин не принимает, назван с причиной, остальные загружаются дальше.
- **Ссылка не меняется.** Переименование меняет только название в менеджере, перенос в другую папку ссылку не трогает. Ссылку можно вставить в блок, поле товара или фид, а папки разобрать потом.
- **Скопировать ссылки.** Отметьте несколько файлов и скопируйте их ссылки разом, через запятую, — готово для текстового поля вроде «Фото для Авито», которое уходит в фид. Отмеченные файлы можно также перенести или удалить.
- **Безопасно на публичном диске.** Тип определяется по самому файлу, программы и веб-страницы не принимаются никогда, SVG пересобирается только из того, что рисует. Настройки: какие типы принимаются, самый большой файл, уменьшение больших фото при загрузке и как называть сохранённые файлы.

### Имена сохранённых файлов
- Новая настройка модуля «Медиа» — **«Имена сохранённых файлов»**: как загружено, транслитом (как раньше), или короткий случайный код вроде `k3f9x2qa7m1b.jpg`. Только для новых загрузок — уже сохранённые картинки свои адреса сохраняют. У файлового менеджера такая же своя настройка.

### Сравнение
- **Стрелки на компьютере.** Когда характеристик много, полоса прокрутки таблицы была далеко внизу; теперь две стрелки держатся на середине окна, пока таблица на экране, и листают её на один столбец товара. На краях и когда всё помещается, они скрываются.

### Исправления
- Вкладка «Вариации»: у выключенной вариации меню статуса, открытое из строки, просвечивало, а значок «этот товар» сдвигался, когда переносился под название.
