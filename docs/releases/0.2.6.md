## What's new

**In short:** two fixes — for shops in FrankenPHP's worker mode and for shops with Redis.

### Fixed
- In FrankenPHP's worker mode a change to blocks — a zone switched off, an edit, a new block — reached the storefront only after the server restarted. It now shows on the next page.
- The "Cache and sessions" screen reported a working Redis or Valkey as not answering.

---

## Что нового

**Главное:** два исправления — для магазинов в режиме воркера FrankenPHP и с Redis.

### Исправлено
- В режиме воркера FrankenPHP изменения блоков — выключенная зона, правка, новый блок — появлялись на витрине только после перезапуска сервера. Теперь они видны на следующей же странице.
- Экран «Кэш и сессии» показывал работающий Redis или Valkey как неотвечающий.
