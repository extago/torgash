## What's new

**In short:** CDEK delivery, FrankenPHP worker mode — pages about three times faster, updates from GitHub.

### CDEK delivery
- To a pickup point, to a parcel terminal and by courier — each its own shipping method.
- The price is worked out live by tariff (Parcel, Express, Economy parcel), with VAT and insurance.
- Towns and pickup points load and update by themselves.
- A customer in a village without a pickup point is offered the nearest towns that have one.
- Waybills right from the order: create, print the waybill and the A6 label, follow the status, cancel. Cash on delivery for exactly what is still owed.

### Faster pages
- FrankenPHP worker mode (Laravel Octane): the application starts once and serves requests without restarting — measured about three times faster.

### Updates from GitHub
- When the update server cannot be reached, the shop takes updates from GitHub releases. Every package's signature is checked as before.

### Cart
- The basket's lines are tidier, on a phone too.

### Fixed
- "You may also like" under the basket did not add products.
- A Russian shop saved product names as English ones, marked "(EN)". Content is now written in the shop's language.
- Times of orders, letters and backups were off: everything now runs on the shop's time zone.
- Some strings stayed English when the module that translated them was not installed.
- Pickup asked for a delivery address.
- Demo prices were in dollars instead of the shop's currency.

## Что нового

**Главное:** доставка СДЭК, режим воркера FrankenPHP — страницы примерно втрое быстрее, обновления с GitHub.

### Доставка СДЭК
- До пункта выдачи, до постамата и курьером — каждый вариант отдельным способом доставки.
- Стоимость считается онлайн по тарифу («Посылка», «Экспресс», «Экономичная посылка»), с НДС и страховкой.
- Города и пункты выдачи загружаются и обновляются сами.
- Покупателю из села без пункта выдачи предлагаются ближайшие города, где пункт есть.
- Накладные прямо из заказа: создать, распечатать накладную и этикетку A6, следить за статусом, отменить. Наложенный платёж — ровно на сумму, которую осталось оплатить.

### Страницы быстрее
- Режим воркера FrankenPHP (Laravel Octane): приложение запускается один раз и обслуживает запросы без перезапуска — по замерам примерно втрое быстрее.

### Обновления с GitHub
- Если сервер обновлений недоступен, магазин берёт обновления из релизов на GitHub. Подпись каждого пакета проверяется, как и раньше.

### Корзина
- Строки корзины аккуратнее, в том числе на телефоне.

### Исправлено
- «Вам может понравиться» под корзиной не добавляло товары.
- Русский магазин записывал названия товаров как английские, с пометкой «(EN)». Теперь контент пишется на языке магазина.
- Время заказов, писем и резервных копий отставало: теперь всё идёт по часовому поясу магазина.
- Часть строк оставалась на английском, если переводивший их модуль не установлен.
- Самовывоз требовал адрес доставки.
- Демо-цены были в долларах, а не в валюте магазина.
