## What's new

**In short:** everything in [0.2.1](https://github.com/extago/torgash/releases/tag/v0.2.1) — CDEK delivery, worker mode, updates from GitHub, the new cart — plus fixes from installing it on a live shop. **Install this one.**

### Changed
- You choose the shop's base language: Languages → "Make it the base". A shop in one language makes it the base and switches the others off — the admin's content-language switcher then disappears.

### Fixed
- The update to 0.2.2 rolled itself back on shops that had chosen a time zone before.
- Restoring a backup — and with it an update's automatic rollback — failed on servers where PostgreSQL extensions belong to the superuser ("must be owner of extension pg_trgm").

## Что нового

**Главное:** всё из [0.2.1](https://github.com/extago/torgash/releases/tag/v0.2.1) — доставка СДЭК, режим воркера, обновления с GitHub, новая корзина — плюс исправления после установки на живой магазин. **Ставьте эту версию.**

### Изменено
- Базовый язык магазина выбираете вы: «Языки → Сделать базовым». Если магазин на одном языке, сделайте его базовым и выключите остальные — переключатель языка контента в админке пропадёт.

### Исправлено
- Обновление до 0.2.2 само откатывалось у магазинов, где раньше был выбран часовой пояс.
- Восстановление резервной копии — а с ним и автоматический откат обновления — не работало на серверах, где расширения PostgreSQL принадлежат суперпользователю (ошибка «must be owner of extension pg_trgm»).
