## What's new

**In short:** visitors now get pages kept ready far more often, especially those arriving from adverts; the speed report no longer shows pages that "took" hours; the System page is easier to read.

### Speed
- **A click on an advert gets a page kept ready.** Advertising tags in the address (Yandex Direct, Google Ads, VK and others) no longer make it a different page, and the first click leaves the page ready for the next visitor. Your counters still see the tags.
- **A page is now kept for a day instead of an hour.** A change in the admin still throws it away at once, and words like "3 days left" limit how long a page is kept. If the page cache settings have ever been saved, your shop keeps the old number: on System → Cache and sessions open "Settings of the page cache" and set "Keep a page for, minutes" to 1440.
- **Visitors who accepted cookies and those who did not now share the same kept pages.** Counters still run only with the visitor's consent: the banner and the counters are added for each visitor separately.
- **Updates of the search index and of the CDEK and Nova Poshta directories no longer throw kept pages away.**
- **A new list, "Why pages were thrown away", on System → Cache and sessions:** what happened, where from and how many times, the last 30 cases.

### Speed report
- **Fixed:** the first page after a server restart was timed from the moment the server started, so it could appear to take hours. Times recorded before this update stay in the report until they expire, after 30 days by default.

### System page
- **The page is rearranged:** short facts in rows of one height, then the longer blocks in two columns.
- **Installing an update from a file and the update server's address now open in windows**, so the Updates block stays short.
- **Known vulnerabilities are one row per library:** the version installed and the version that fixes it, instead of a long list of repeats.
- **Fixed:** an update file that was refused, for example one that is not signed, gave no message. The page now says why.
- **Fixed:** the notes of a new version were shown as raw text. They are now formatted.

## Что нового

**Главное:** посетители теперь намного чаще получают готовые страницы, особенно те, кто пришёл с рекламы; отчёт о скорости больше не показывает страницы, которые «открывались» часами; страница «Система» стала понятнее.

### Скорость
- **Переход по рекламе получает готовую страницу.** Рекламные метки в адресе (Яндекс Директ, Google Ads, VK и другие) больше не делают её другой страницей, а первый переход оставляет страницу готовой для следующего посетителя. Ваши счётчики метки по-прежнему видят.
- **Страница теперь хранится сутки, а не час.** Изменение в админке по-прежнему выбрасывает её сразу, а слова вроде «осталось 3 дня» ограничивают срок хранения. Если настройки кэша страниц уже сохранялись, в магазине осталось старое число: на экране «Система → Кэш и сессии» откройте «Настройки кэша страниц» и поставьте в поле «Хранить страницу, минут» значение 1440.
- **Принявшие и не принявшие cookie теперь получают одни и те же готовые страницы.** Счётчики по-прежнему запускаются только с согласия посетителя: баннер и счётчики добавляются для каждого отдельно.
- **Обновление поискового индекса и справочников СДЭК и Новой почты больше не выбрасывает готовые страницы.**
- **Новый список «Почему страницы выбрасывались» на экране «Система → Кэш и сессии»:** что случилось, откуда и сколько раз, последние 30 случаев.

### Отчёт о скорости
- **Исправлено:** первую страницу после перезапуска сервера считали от момента его запуска, поэтому она могла «открываться» часами. Записи, сделанные до этого обновления, останутся в отчёте, пока не устареют: по умолчанию через 30 дней.

### Страница «Система»
- **Страница перестроена:** короткие факты в рядах одной высоты, ниже длинные блоки в две колонки.
- **Установка обновления из файла и адрес сервера обновлений теперь открываются в окнах**, поэтому блок обновлений остаётся коротким.
- **Известные уязвимости идут по одной строке на библиотеку:** установленная версия и версия с исправлением вместо длинного списка повторов.
- **Исправлено:** отклонённый файл обновления, например неподписанный, не давал никакого сообщения. Теперь страница объясняет причину.
- **Исправлено:** заметки к новой версии показывались сырым текстом. Теперь они оформлены.
