## What's new

**In short:** everything in [0.2.1](https://github.com/extago/torgash/releases/tag/v0.2.1) in a package that installs over 0.2.0.

### Fixed
- 0.2.1 could not be installed over 0.2.0. Worker mode now starts from `index.php`: in the Caddyfile, `worker index.php`.
- A time zone chosen before the update is picked up by itself, and times stop being three hours early.
- The backups list shows a finished backup by itself; no need to reload the page.
- The update's description on the System page is in the admin's language.

## Что нового

**Главное:** всё из [0.2.1](https://github.com/extago/torgash/releases/tag/v0.2.1) в пакете, который ставится поверх 0.2.0.

### Исправлено
- 0.2.1 не ставилась поверх 0.2.0. Режим воркера теперь запускается из `index.php`: в Caddyfile — `worker index.php`.
- Если часовой пояс был выбран до обновления, магазин переходит на него сам, и время перестаёт отставать на три часа.
- Список резервных копий сам показывает готовую копию, страницу обновлять не нужно.
- Описание обновления на странице «Система» показывается на языке админки.
