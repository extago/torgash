## What's new

**In short:** fixes. The button in a code letter confirms a new email again — on any device; the catalogue checks no longer report the sizes of one card for a missing description or photo they take from their main product; and the uploads self-test no longer raises a false alarm on a server that serves the test file as text.

### Fixes
- **"Continue on this device" in a letter confirming an email did nothing** — only typing the code worked. The button now confirms the address: in the browser where you are signed in, or on another device (a phone's mail app) without signing anybody in there. Letters whose code is waited for on the page that asked (a form, the checkout) no longer carry a button that led nowhere — only the code.
- **"Every product page has something to say about the product"** and **"Every product on sale has a photograph"** reported sizes that take their description and photos from their card's main product. Now what the page really shows is checked; a card with nothing at all is reported once, not once per size. A description written by an SEO template counts too.
- **The uploads self-test said "the server EXECUTED it"** when the server was in fact serving the test file as plain text — a false alarm, not a hole. Fixed. If you saw that warning before, press "Run the self-test" again.
- The self-test's advice named a tool of the engine's own development instead of speaking about your server, and had no lines for FrankenPHP. It now explains that the server's configuration is yours to change and gives lines for FrankenPHP, Caddy, nginx and Apache.

## Что нового

**Главное:** исправления. Кнопка в письме с кодом снова подтверждает новую почту — на любом устройстве; проверки каталога больше не ругают размеры одной карточки за описание и фото, которые они берут у основного товара; самопроверка загрузок больше не поднимает ложную тревогу, когда сервер отдаёт тестовый файл текстом.

### Исправления
- **«Продолжить на этом устройстве» в письме с подтверждением почты ничего не делала** — срабатывал только ввод кода вручную. Теперь кнопка подтверждает адрес: в браузере, где вы вошли, или на другом устройстве (в почте на телефоне) — без входа в аккаунт там. В письмах, код из которых ждёт страница, где его запросили (форма, оформление заказа), больше нет кнопки, которая никуда не вела, — только код.
- **«Каждой странице товара есть что сказать о товаре»** и **«У каждого товара в продаже есть фотография»** находили размеры, которые берут описание и фото у основного товара карточки. Теперь проверяется то, что действительно видно на странице; карточка совсем без описания или фото — одна строка, а не по одной на размер. Описание из SEO-шаблона тоже засчитывается.
- **Самопроверка загрузок писала «сервер ИСПОЛНИЛ»**, когда сервер на самом деле отдавал тестовый файл обычным текстом, — ложная тревога, а не дыра. Исправлено. Если вы видели это предупреждение раньше, нажмите «Запустить самопроверку» ещё раз.
- В подсказке самопроверки упоминался инструмент, на котором разрабатывают сам движок, вместо вашего сервера, и не было строк для FrankenPHP. Теперь сказано, что настройки сервера меняете вы, и даны строки для FrankenPHP, Caddy, nginx и Apache.
